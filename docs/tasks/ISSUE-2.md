# Задача #2: лёгкий веб-интерфейс поверх API

**Описание**: помимо самого API, преподаватель ожидает возможность
визуально посмотреть данные без работы с curl/Swagger — лёгкий дашборд
по образцу референса (боковое меню по сущностям + сводные счётчики
на главной), без отдельного frontend-фреймворка и сборки.

**Критерии приёмки**:
- Статический интерфейс на чистом HTML/JS, без build-инструментов.
- Главная показывает количество депутатов/комиссий/заседаний.
- Разделы: Депутаты, Комиссии (с составом и заседаниями), Посещаемость.
- Интерфейс использует уже существующее API, без новых бизнес-эндпоинтов.
- Доступен по отдельному пути `/ui`, не мешает работе самого API.

**Ветка**: `feature/lightweight-ui`
