# Задача #3: развёртывание в Linux-среде (ЛР2)

**Описание**: приложение должно работать как управляемая Linux-служба на
двух отдельных виртуальных машинах (сервер приложения + сервер БД),
без ручного запуска из IDE и без контейнеров.

**Критерии приёмки** (по пунктам задания ЛР2):
- Две VM с host-only сетью и статической адресацией, SSH только по ключам.
- root по SSH запрещён, есть разделение на admin/duma-пользователей.
- Приложение — systemd-служба: автостарт, автоперезапуск при сбое.
- PostgreSQL на отдельной машине, роль с минимальными правами.
- firewall: БД доступна только с app-server, порт приложения — клиентам.
- Настройки (.env) вне репозитория, права 600.
- Скрипты, позволяющие повторить развёртывание с нуля.

**Ветка**: `feature/linux-deployment`
