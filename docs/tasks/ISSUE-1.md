# Задача #1: фильтрация заседаний по статусу

**Описание**: секретарю думы нужно быстро получать список заседаний в
конкретном статусе (например, только запланированные), не выгружая
весь список и не фильтруя вручную.

**Критерии приёмки**:
- `GET /meetings` принимает необязательный query-параметр `status`.
- При некорректном значении статуса — `422`.
- Существующее поведение (без параметра) не меняется.
- Добавлен тест на фильтрацию.
- Обновлена документация API.

**Ветка**: `feature/meetings-status-filter`
